# Family Tree

A private website for building a visual family tree. You can add people, link
them together, and record details, photos and stories for each person.

## Your data stays on your computer
Nothing you enter is uploaded anywhere. You save your tree to a
`.familytree` file on your computer, then open that file next time to carry on.
The website also keeps an automatic backup in your browser in case you forget
to save.

**Tip:** keep a second copy of your `.familytree` file (for example on a USB
drive) so you never lose your work.

## Using it
Open the website link in **Chrome** or **Edge** for the best experience. In
those browsers "Save" updates the same file each time. Safari and Firefox
download a new, dated copy each time you save instead.
